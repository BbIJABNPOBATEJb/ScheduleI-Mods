# Changelog

## 1.0.0 - 2026-09-30

- First release.
- Mute (or lower) the game while minimized / unfocused, fading back in on return.
- Pause world sounds while the pause menu is open; menu clicks stay audible, music optional.
- Options in the game's Settings → Audio tab.
- Supports both IL2CPP (default) and Mono (`alternate`) branches.
