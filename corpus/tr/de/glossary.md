# German glossary (de)

Consult this before translating a chunk and follow it strictly; add new recurring terms as you go
(never change an existing entry without updating every chunk that uses it).

## Conventions

- **Address: "du" everywhere** — UI, tutorials, hints, system messages and dialogue ("Bist du sicher?",
  "Klicke auf ...", "deinem Bericht"). Lowercase "du/dein/dir" (no capitalized "Du").
  Exception: police officers speak "Sie" to the player ("Bleiben Sie stehen!"). All other NPCs, including
  shopkeepers, say "du".
- **Buttons / actions / input prompts: infinitive**, short: "Kaufen", "Schließen", "Abbrechen",
  "Einstellungen übernehmen", "In den Warenkorb", "Dünger anwenden". Titles/labels are nouns: "Tastenbelegung".
- **Instructions / hints: du-imperative**: "Klicke auf ein Produkt ...", "Wähle ...", "Drücke ...".
  "Click" → "Klicke"; "Press" → "Drücke"; "Click and hold X" → "Halte X gedrückt"
  (e.g. "Halte die rechte Maustaste gedrückt").
- **"(Hold) X" prompts** → "(Halten) X" with X as infinitive: "(Halten) Konsumieren", "(Halten) Springen".
- **ALL-CAPS keys stay ALL-CAPS**; write ß as SS in caps ("SCHLIESSEN", "GROSSER GEWINN!"); umlauts stay (Ä Ö Ü).
- **Ellipsis**: three dots "...", no space before ("Gegenstand hinzufügen...", "Menge..."). Never "…".
- Quotation marks in German text: „…“. Money stays "$" in front: "${0}", "+${0} Bonus". Units unchanged (g, mph, °F).
- Keep leading hint markers ("^", "- ", "+ ", "• ") and their spacing as in the key.
- Proper names, brands, stores, places and strains stay in Latin spelling: Benzies, Gas-Mart, Northtown,
  Downtown, Bleuball's Boutique, Bud's Bar, Albert Hoover, OG Kush, SpeedGrow, PGR, Taco Ticklers.
  Generic words combined with a name are hyphen-coupled: "OG Kush Seed" → "OG-Kush-Samen",
  "Granddaddy Purple Seed" → "Granddaddy-Purple-Samen".
- Effect / status labels are uninflected, capitalized adjectives ("Beruhigend", "Feindselig");
  face expressions in the character creator likewise ("Agitated" → "Aufgebracht").
- Map labels with "\n": keep exactly one break per break in the key; hyphenate if the break splits a compound
  ("Basketball\nCourt" → "Basketball-\nplatz").
- Dialogue: casual spoken German, slang welcome ("Gras", "Koks", "Kohle", "verticken"); don't sanitize.
