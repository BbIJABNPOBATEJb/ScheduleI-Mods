# Italian glossary (it)

Consult this before translating a chunk; add new recurring terms as you go. These choices are binding:
use exactly these words everywhere.

## Conventions

- UI instructions and system text address the player informally with "tu": "Premi", "Seleziona", "Vuoi davvero...?",
  "Clicca e tieni premuto...". Prefer gender-neutral phrasing for the player ("Confermi?", "Vuoi davvero...?",
  "IN MANETTE") instead of "Sei sicuro/a?".
- Dialogue: NPCs say "tu" to the player and use slang. Formal NPCs (shopkeepers, bank/real-estate staff, police
  addressing a suspect) use "Lei" (capitalized): "Posso aiutarLa?", "Mi mostri i documenti".
- Buttons, actions and input prompts use the 2nd-person imperative (tu): "Compra", "Chiudi", "Annulla", "Accetta",
  "Applica impostazioni", "Aggiungi al carrello", "Raccogli". Sentence case, not Title Case ("Gestione attività",
  not "Gestione Attività"). ALL-CAPS keys stay ALL-CAPS (accents allowed: "SARÀ", "CAFFÈ").
- Input prompts with "(Hold)": "(Tieni premuto) <azione>", e.g. "(Tieni premuto) Consuma", "(Tieni premuto) Sniffa".
- "Click" → "Clicca", "Click and hold" → "Clicca e tieni premuto/a/i" (agree with the object), "Press" → "Premi",
  "Hold" (in a sentence) → "Tieni premuto".
- Proper names, brands, stores, places and strains stay in Latin spelling, untranslated: Benzies, Gas-Mart,
  Northtown, Downtown, Hyland Point, Bleuball's Boutique, Bud's Bar, Albert Hoover, OG Kush, SpeedGrow, PGR.
  Italian articles/prepositions go around them: "al Gas-Mart", "a Northtown", "i Benzies".
- Ellipsis stays as three dots "..." (not "…"). Money stays "$" in front: "${0}", "+${0} di bonus".
- Dates: "Coming January {0}" → "In arrivo il {0} gennaio" (month names lowercase).
- Use "ecc." for "etc", Italian quotes are not needed (keep plain quotes if the key has them).
