# Korean glossary (ko)

Read this before translating a chunk and follow it strictly. If you add a recurring term, append it here.

## Conventions

- **UI / system text** (cat ui, tooltips, descriptions, notifications): formal polite style.
  - Instructions: 하세요체 — "클릭하세요", "선택하세요", "제안을 수락하거나 역제안하세요".
  - Statements / descriptions: 합니다체 — "자동으로 가져옵니다", "되돌릴 수 없습니다."
  - Confirmation questions: "-하시겠습니까?" — "이 세이브를 덮어쓰시겠습니까?", "Are you sure?" → "정말 진행하시겠습니까?"
  - Status labels / short info: noun phrase, no final period — "최근 구매 내역 없음", "여러 개 동시 편집 불가", "도착".
  - Avoid "당신" in UI when the sentence works without a subject; use it only when needed ("당신에게 적대적으로 변합니다").
- **Buttons, menu items, actions, key bindings**: short noun forms, never a full sentence.
  Prefer Sino-Korean nouns ("구매", "취소", "수락", "시작", "조준", "섭취", "재시작"); otherwise the -기 form
  ("닫기", "지우기", "비료 주기", "덩어리 부수기", "장바구니에 담기").
  Same word for Title case and ALL-CAPS keys (Korean has no case): "Close"/"CLOSE" → "닫기", "BUY" → "구매".
- **"(Hold) X" input prompts** → "(길게) X" with X as a noun/-기 form: "(길게) 섭취", "(길게) 점프",
  "(길게) 피우기", "(길게) 코로 흡입", "(길게) 내용물 비우기".
- Mouse / keys: "Click" → "클릭하세요"; "Click and hold" → "길게 클릭하세요"; "Press" → "누르세요";
  "Hold (key)" → "길게 누르세요"; right/left mouse button → "마우스 오른쪽/왼쪽 버튼". [SPACEBAR] → [스페이스바].
- **Dialogue** (cat dialogue): natural spoken Korean.
  - Street NPCs, customers, dealers, Uncle Nelson, Benzies thugs, friends → 반말 to the player ("야, 물건 있어?", "돈 가져왔냐?").
    Address the player as "너" (or drop the subject).
  - Shopkeepers, clerks, receptionists, bank/realty staff, doctors → 해요체 ("어서 오세요", "이거 사실 거예요?"); may call the player "손님".
  - Police → 합쇼체/해요체 mix, curt and official ("멈추십시오!", "신분증 보여 주세요.").
  - Player choice lines: 반말 to street NPCs, 해요체 to formal NPCs. Keep swearing and crude humor (씨발/젠장/빌어먹을 as fits the source's strength).
- **Proper names stay in Latin script**: people (Uncle Nelson, Albert Hoover, Benji Coleman), the Benzies cartel,
  brands/stores (Gas-Mart, Dan's Hardware, Bleuball's Boutique, Bud's Bar, Ray's Realty, Taco Ticklers, Thrifty Threads),
  places (Hyland Point, Northtown, Westville, Downtown, Docks, Suburbia, Uptown, Northville), strains/products
  (OG Kush, Sour Diesel, Granddaddy Purple, Baby Blue, Biker Crank, Glass), brand-name items (PGR, SpeedGrow, Cuke,
  Viagor, Addy, Mega Bean), vehicles (Shitbox, Veeper, Hounddog), the game title SCHEDULE I, casino game "Ride the Bus".
  Only the generic part is translated: "OG Kush Seed" → "OG Kush 씨앗", "Apply PGR" → "PGR 주기".
- **Particles after Latin names**: attach directly (no space) and choose by the English pronunciation's final sound:
  "Benzies와/를/는", "Gas-Mart에서", "Albert Hoover의", "Uncle Nelson이/을". When unsure, prefer 에서/의/에게 which don't vary.
- Generic map labels (not brand names) are translated: "Basketball\nCourt" → "농구\n코트", "Car Wash" → "세차장",
  "Canal" → "운하", "Bridge" → "다리", "Casino" → "카지노". Keep the same number of \n (split a Korean word/phrase at a natural point).
- Punctuation: keep "..." (three dots, not "…"), "!", "?", ":" as in the key. Money stays "$" in front: "${0}", "+${0} 보너스".
  Units stay as in the key (g, mph, °F, oz). Dates: "January {0}" → "1월 {0}일".
- Counters: "{0} Others" (items) → "외 {0}개"; people → "{0}명"; days → "{0}일"; units of product → "{0}개".
- Rank tiers keep Roman numerals after the rank: "수금책 III", "구역 보스 V".
