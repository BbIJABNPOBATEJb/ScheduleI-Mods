# Ukrainian glossary (uk)

Consult this before translating a chunk and follow it strictly. Add new recurring terms as you go
(never change an existing entry without updating every chunk that uses it).

## Conventions

- **Address.** UI instructions, hints, tooltips and system text use the formal "ви" with imperatives:
  "Натисніть", "Оберіть", "Прийміть пропозицію", "Ви впевнені?". Dialogue and texts/messages from NPCs use
  "ти" to the player (street slang welcome); only formal NPCs (shopkeepers, officials, police, the bank,
  realtor) use "ви". The player's own reply choices in dialogue talk to NPCs with "ти" unless the NPC is formal.
- **Buttons / actions / input prompts** use the infinitive: "Купити", "Закрити", "Скасувати",
  "Застосувати налаштування", "Забрати готівку". "Add to Cart" → "До кошика".
- **"(Hold) X"** → "(Утримати) X" with X in the infinitive: "(Утримати) Спожити", "(Утримати) Нюхнути".
- **"Click"** → "Натисніть" (also "Click a product" → "Натисніть на товар"); **"Click and hold"** →
  "Натисніть і утримуйте"; "Press <Input_X>" → "Натисніть <Input_X>".
- **ALL-CAPS** keys stay ALL-CAPS ("ACCEPT" → "ПРИЙНЯТИ", "BUSTED" → "ЗАМЕЛИ").
- **Ellipsis** stays as three dots "..." (not "…"). Keys ending with ":" / "?" / "..." keep it.
- **Apostrophe**: use the plain ASCII apostrophe `'` (U+0027): "об'єкт", "ім'я", "перемир'я". Do not use ʼ or ’
  (game fonts may lack them).
- **Letter ґ** is used where standard: "ґрунт".
- **Money / units** as in the key: "${0}", "+${0} бонус", "g", "mph", "°F". Numbers keep `{0}` slots.
- **Proper names stay in Latin**: people (Albert Hoover, Benji Coleman, Uncle Nelson), Benzies, stores and
  brands (Gas-Mart, Bleuball's Boutique, Bud's Bar, Dan's Hardware), districts (Northtown, Westville, Downtown,
  Docks, Suburbia, Uptown, Northville, Hyland Point), strains/products (OG Kush, Sour Diesel, Glass), additives
  PGR and SpeedGrow, vehicle models. Grammar goes around them: "Вплив Benzies у Northtown", "у Gas-Mart",
  "Насіння OG Kush".
- Generic place/property types ARE translated: Bungalow → Бунгало, Car Wash → Автомийка, Casino → Казино,
  Canal → Канал, Bridge → Міст, Motel → Мотель, Barn → Сарай, Warehouse → Склад, Storage Unit → Складське
  приміщення, Laundromat → Пральня, Post Office → Пошта (brand names like Taco Ticklers stay Latin).
- Character-creator face expressions agree with "обличчя" (neuter): "Agitated" → "Схвильоване".
  Hairstyles: "Bowl Cut" → "Під горщик", "Buzz Cut" → "Під машинку", "Afro" → "Афро".
- Tone: cheeky and crude where the original is; do not sanitize or moralize. Avoid russisms
  (not "крутий бізнесмен", "получити", "прийняти участь"), write natural Ukrainian.
